# Ashen Vale (прототип)

Личная hack-and-slash игра на Godot 4.3 (GDScript). Оригинальный мир и названия.
Механики: движение джойстиком, 4 навыка, враги, лут по редкости, уровни.

Запуск: открыть папку `game/` в Godot 4.3 и нажать F5.
Клавиатура для проверки на ПК: Space — удар, Q — вспышка, E — рывок, R — лечение.
Android: Project → Export → Android (нужен Android SDK) или через GitHub Actions.
